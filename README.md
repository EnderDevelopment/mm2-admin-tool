# Roblox Admin Tool

This project contains a Roblox admin tool with commands for godmode, invisibility, and ESP. The tool is designed to be easy to use and integrate into any Roblox game. It provides a simple GUI for players to toggle these admin features on and off.

## Install

1. Open Roblox Studio and create a new place or open an existing one.
2. Insert a ServerScriptService if it doesn't already exist.
3. Insert a StarterPlayerScripts if it doesn't already exist.
4. Copy the contents of `AdminTool.server.lua` into a new Script in the ServerScriptService.
5. Copy the contents of `AdminTool.client.lua` into a new LocalScript in the StarterPlayerScripts.

## Use

1. Test the game and use the admin tool GUI to toggle godmode, invisibility, and ESP.
2. The GUI will appear in the center of the screen with three buttons: "Toggle Godmode", "Toggle Invisibility", and "Toggle ESP".
3. Click on any of the buttons to activate or deactivate the corresponding feature.
